Have you ever wanted to use a tool to parse the manually typed up "stuff" that lives in a tnsnames.ora file, to be absolutely certain that it is correct? Ever wanted some tool to count all the opening and closing brackets match? I may just have the very thing for you.

All the grammar, lexer and parser code can be found on [my GitHub](https://github.com/NormanDunbar/grammars-v4/tree/master/tnsnames). The [readme](https://github.com/NormanDunbar/grammars-v4/blob/master/tnsnames/README.md) file is your friend.

Download the binary file [TNSNames.Parser.zip](/downloads/TNSNames.Parser.zip) and unzip it. [Source code](https://github.com/NormanDunbar/grammars-v4/tree/master/tnsnames "Source Code on Github") is also available on Github.

When unzipped, you will see the following files:

- `README.*` - this should be obvious!
- `tnsnames_checker.sh` - Unix script to run the utility.
- `tnsnames_checker.cmd` - Windows batch file to run the utility.
- `antlr-4.8-complete.jar` - Parser support file.
- `tnsnames_checker.jar` - Parser file.
- `tnsnames.test.ora` - a seriously _invalid_ tnsnames.ora to test the utility with.

The [README](https://github.com/NormanDunbar/grammars-v4/tree/master/tnsnames/examplesdoc) file is your best friend!

All the utility does is scan the supplied input file, passed via standard in, and writes any syntax or semantic problems out to standard error.

### Before You Begin

The files in the download ar the raw files, I wrote the grammar, lexer and parser, a couple of test harnesses and that's what you get. See [this post](/2014/12/03/tnsnames-checker-utility) for a full-blown utility to do all the hard work for you.

### Working Example

If there were no errors in the `tnsnames.test.ora` file, the output would look like the following:

```bash
./tnsnames_checker.sh < tnsnames.test.ora

Tnsnames Checker.
Using grammar defined in tnsnames.g4.
Parsing ....
Done.
```
